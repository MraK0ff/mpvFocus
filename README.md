# mpvFocus

[![GitHub release (latest SemVer)](https://img.shields.io/github/v/release/MraK0ff/mpvFocus.svg?logo=github\&label=GitHub\&cacheSeconds=3600)](https://github.com/MraK0ff/mpvFocus/releases/latest)
[![GitHub all releases](https://img.shields.io/github/downloads/MraK0ff/mpvFocus/total?logo=github\&cacheSeconds=3600)](https://github.com/MraK0ff/mpvFocus/releases/latest)

**mpvFocus is a fork of [mpvEx](https://github.com/marlboro-advance/mpvEx), designed specifically for Android TV and Google TV devices.**

Built on top of libmpv and Jetpack Compose, mpvFocus focuses on delivering a proper TV-first experience with:

* optimized D-pad navigation
* remote-first controls
* modern 10-foot UI
* focus-aware interaction
* smooth playback
* power-user mpv capabilities

Originally derived from [mpv-android](https://github.com/mpv-android/mpv-android), mpvFocus continues the foundation established by mpvEx while heavily improving Android TV usability and remote navigation.

## Why mpvFocus?

Most Android media players are either:

* mobile-first
* touch-first
* bloated
* ad-supported
* or lack advanced playback capabilities

mpvFocus is built around a different idea:

> A powerful mpv-based player with a proper Android TV experience.

This means:

* predictable remote navigation
* focus-safe UI
* minimal interaction friction
* stable playback
* smooth performance
* clean architecture
* advanced playback without unnecessary complexity
