# Git Workflow Rules

## Branching
- feature/*
- fix/*
- refactor/*
- perf/*
- tv/*

## Commit style
- feat:
- fix:
- refactor:
- perf:
- tv:

## Rules
- Small atomic commits only
- Never mix refactor + feature in one commit
- Keep history readable

## PR rules
- Explain why change is needed
- Include performance impact if relevant
- Include TV UX impact if applicable
